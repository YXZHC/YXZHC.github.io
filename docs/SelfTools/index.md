# 欢迎来到我的「自制工具集」 🛠️
🎉 这里汇聚了专为创作者和学习者打造的实用工具，用技术简化复杂任务，助力效率飞升！

## 🌟 工具集概览
「自制工具集」精心整合**机器人草图绘制与坐标规划工具**和**轻量级答题系统**两大核心工具，无论是机器人设计开发，还是知识测评学习，都能在这里找到趁手的解决方案 🚀

## 🛠️ 工具软件
### 1. 机器人草图绘制与坐标规划工具 🤖✏️
- **功能亮点**：提供直观的绘图界面，支持自由绘制机器人外形草图，一键生成3D模型预览；内置智能坐标规划算法，根据草图快速规划机器人运动轨迹，支持导入CAD文件进行深度编辑；还能输出精确的坐标数据，方便后续编程开发 📐
- **适用场景**：机器人爱好者原型设计、科研团队方案规划、工程师前期建模等场景都能轻松驾驭

### 2. 轻量级答题系统 📚
- **功能亮点**：极简界面设计，快速创建单选题、多选题、判断题题库；支持一键分享答题链接，实时查看答题结果与正确率；具备云端存储功能，轻松管理多套试题，满足快速测试需求 ⏱️
- **适用场景**：教师随堂小测、企业快速考核、个人知识自测等场景的得力助手

## 💻 技术栈揭秘
本工具集采用前沿技术开发，确保稳定流畅：
- **前端**：Vue3 + Three.js + Element Plus，打造流畅的绘图交互与简洁界面 🎨
- **后端**：Python Flask + MongoDB，实现高效的数据处理与存储 🔐
- **算法支持**：运用专业的轨迹规划算法和数据加密技术，保障数据安全与功能强大 💡
- **部署**：通过Docker实现容器化部署，提升工具的兼容性与稳定性 🚢
