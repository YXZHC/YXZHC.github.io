# 欢迎来到「答题系统」 🚀
✨ 一个专注于高效学习与便捷易用而开发的答题系统，由我独立开发完成～  

## 🌟 关于这个应用  
「答题系统」是一款为学习者、教育者和培训测试而设计的多功能答题系统，核心目标是让知识测试更智能、更有趣、更高效！📚  

### 🔥 核心亮点  
- **题型支持**：单选题、多选题、判断题 📸  
- **动态存储引擎**：采用全局智能动态存储功能,无感知存储实时进度,确保答题进度不丢失！ ✅  
- **个性化学习报告**：答题结束系统自动生成答题报告，答题时间，正确率一目了然！ 📊  
- **适配情况**：Windows10 + Windows11，随时随地方便作答 📱  


## 🛠️ 主要功能模块  
### 1. 题库管理系统  
- 支持批量导入/导出题库 📤  
- 混合题库（如「单选题」+「多选题」+「判断题」）🏷️  

### 2. 智能组卷功能  
- 自动组卷：按题型比例智能抽题 🤖  
- 支持随机乱序、选项随机排列防作弊 🎲  

### 3. 答题交互体验  
- 实时进度条显示 + 计时提醒 ⏰  
- 测试模式下支持查看题目正确答案提示 📐  


## 🌱 适用场景  
- **理论考试**：课后自测、考前模拟、错题复盘 ✨  


## 💻 技术栈揭秘  
这个项目从0到1全由我独立开发，用到的技术包括：  
- **UI**：完全采用Labview设计，核心部分采用多种架构，稳定高效！ 🚀  
- **数据处理**：使用原生Microsoft dll库,减少内存使用，提升执行效率!🐍
