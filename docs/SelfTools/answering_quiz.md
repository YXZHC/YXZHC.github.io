# 欢迎来到「轻量化答题」系统 🚀
✨ 一个专注于高效学习与趣味互动的智能答题平台，由我独立开发完成～  

## 🌟 关于这个应用  
「轻量化答题」是一款为学习者、教育者和企业培训设计的多功能答题系统，核心目标是让知识测试更智能、更有趣、更高效！📚  

### 🔥 核心亮点  
- **全题型支持**：单选题、多选题、判断题、填空题、简答题，甚至支持图片/公式题 📸  
- **智能判分引擎**：自动识别填空关键词匹配度，简答题支持关键词加权评分 ✅  
- **个性化学习报告**：实时生成正确率分析、知识薄弱点图谱、答题速度趋势图 📊  
- **多端适配**：PC网页端 + 移动端自适应，随时随地方便作答 📱  


## 🛠️ 主要功能模块  
### 1. 题库管理系统  
- 支持Excel批量导入/导出题库 📤  
- 自定义分类标签（如「考研政治」「CPA会计」「Python入门」）🏷️  
- 题目难度分级（初级/中级/高级）+ 知识点关联 🔖  

### 2. 智能组卷功能  
- 手动组卷：自由勾选题目生成试卷 ✏️  
- 自动组卷：按知识点/难度/题型比例智能抽题 🤖  
- 支持随机乱序、选项随机排列防作弊 🎲  

### 3. 答题交互体验  
- 实时进度条显示 + 倒计时提醒 ⏰  
- 错题自动标记 + 一键收藏功能 ❌⭐  
- 答题过程中支持公式编辑器/图片上传 📐  

### 4. 数据统计后台  
- 考生成绩排名实时更新 📈  
- 错题本导出PDF功能 📄  
- 多维度数据报表（周/月/年趋势） 📊  


## 🌱 适用场景  
- **学生党**：课后自测、考前模拟、错题复盘 ✨  
- **教育机构**：在线作业布置、班级竞赛活动、学员能力评估 🏫  
- **企业培训**：新员工考核、岗位技能测评、安全知识竞赛 🏢  
- **个人开发者**：API开放接口支持第三方系统对接 🔌  


## 💻 技术栈揭秘  
这个项目从0到1全由我独立开发，用到的技术包括：  
- **前端**：Vue3 + Vite + Element Plus + ECharts 🚀  
- **后端**：Python FastAPI + JWT认证 + Nginx部署 🐍  
- **数据库**：MySQL（主库）+ Redis（缓存）+ MongoDB（日志）💾  
- **工具链**：Docker容器化 + Git版本控制 + Swagger接口文档 🛠️
