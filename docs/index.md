# 🤖 机器人技术探索者 | Robotics Tech Explorer

欢迎来到我的技术小站！这里专注于分享机器人技术领域的实战经验、代码示例和深度解析，涵盖编程语言、机器人框架、计算机视觉、自主导航等核心领域。希望这些内容能为你的技术探索之路提供助力 🌟

## 📚 核心内容分类

### 💻 编程语言与工具

- **C++** 🛠️：机器人高性能计算核心语言，分享模板编程、内存管理、多线程开发等实战技巧

- **Python** 🐍：快速原型开发首选，涵盖脚本编写、数据分析、机器学习接口封装等最佳实践

- **LabVIEW** 🔌：图形化编程利器，解析 NI 硬件驱动开发、实时系统集成与测控应用案例

### 🤖 机器人开发框架

- **ROS2** 🤖：下一代机器人操作系统，详解组件化架构、DDS 通信、跨平台部署最佳实践

- **Nav2** 🗺️：自主导航核心框架，拆解全局路径规划、局部避障、动态目标跟踪实现原理

- **MNN** 🧠：端侧推理框架实战，分享模型转换、异构加速、边缘设备部署优化经验

### 🔬 计算机视觉与感知

- **YOLO 系列** 🚀：

- YOLOv8 🆕：实时目标检测新标杆，解析改进的 Backbone/Neck 结构与训练技巧

- YOLOv5 🧪：工业级部署首选，分享模型剪枝、量化加速、多平台 SDK 集成经验

- **SLAM** 🌐：同步定位与地图构建，涵盖激光 SLAM（Cartographer）、视觉 SLAM（ORB-SLAM3）核心算法解析

### 🧠 机器人核心算法

- **路径规划** 🧭：Dijkstra/A * 算法优化、动态窗口法（DWA）、人工势场法工程实现

- **运动控制** 🤲：PID 控制调参技巧、模型预测控制（MPC）、力控算法在机械臂中的应用

- **机器学习** 🤖：强化学习在机器人决策中的应用，解析 PPO/DQN 算法与仿真环境搭建
